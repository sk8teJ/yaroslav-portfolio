# Yaroslav — Business & AI Analyst

Одностраничное портфолио на React + Vite. Визуальная концепция: тёмная Apple-inspired эстетика, крупная типографика, широкие проектные секции, чередование светлых и тёмных блоков, RU/EN и адаптивная навигация.

## Требования

- Node.js 20.19+ или 22.12+
- npm

## Запуск в Windows PowerShell

```powershell
cd путь\к\yaroslav-portfolio
npm install
npm run dev
```

Открой адрес, который Vite покажет в терминале (обычно `http://localhost:5173`).

## Проверка production-сборки

```powershell
npm run build
npm run preview
```

## Что нужно заполнить перед публикацией

1. В `src/App.jsx` заменить временные блоки Email и Telegram на реальные адрес и username.
2. Проверить тексты описаний проектов и соответствие текущему состоянию репозиториев.
3. При желании добавить реальные скриншоты проектов вместо CSS-визуализаций в `DashboardVisual`, `KnowledgeVisual` и `WorkflowVisual`.

Проект не содержит выдуманных показателей эффективности. Цифры в декоративном макете аналитического дашборда являются частью иллюстрации, а не заявленными результатами проекта.
